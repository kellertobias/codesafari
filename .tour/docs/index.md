title: Documentation
---

Long-form reference material that doesn't fit a tour, a component page, or a
one-paragraph [glossary entry](glossary:manifest).

A [tour](doc:authoring) is a *path* through the code — ordered, opinionated, and
anchored to real lines. These pages are the opposite: standing reference you
come back to, organised by topic rather than by reading order.

Every folder under `.tour/docs/` becomes a section in the navigation tree on the
left. Start with [authoring](doc:authoring).
